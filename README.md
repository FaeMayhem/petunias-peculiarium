# Petunia's Peculiarium

Companion resource site for the podcast *Petunia's Peculiarium*: true stories from macabre history, beginning in Boston, told by Petunia Pickman.

Live site: https://faemayhem.github.io/petunias-peculiarium/

## Layout

- `index.html`: home page and episode list
- `episodes/_template.html`: copy this to `episodes/epNN.html` for each episode's resource page
- `images/epNN/`: images for each episode (public domain or openly licensed, credited on the page)
- `assets/style.css`: shared styles, with light and dark themes

Plain HTML and CSS, no build step. GitHub Pages serves the `main` branch root.
